# ТЗ: autocad-mcp-polisnab
### Кастомизация MCP-сервера для 2D-черчения модулей (бытовок) в AutoCAD

---

## 1. Цель

Форкнуть и доработать `puran-water/autocad-mcp` (MIT license) так, чтобы Claude через MCP мог строить 2D-чертежи модулей Полиснаба (планы, разрезы) с соблюдением фирменного стандарта оформления — слои, размерный стиль, штамп, типовые узлы (проёмы, двери, окна, вентиляция).

Итог: не «универсальный CAD-помощник», а инструмент, который черчит бытовки строго по внутреннему стандарту, а не как получится.

---

## 2. Базовый репозиторий

- Источник: https://github.com/puran-water/autocad-mcp
- Лицензия: MIT — форк, изучение и переработка кода разрешены без ограничений.
- Бэкенды: `file_ipc` (живой AutoCAD через AutoLISP-диспетчер) и `ezdxf` (headless, без AutoCAD).
- Уже реализовано и **не трогаем на первом этапе**: диспетчер команд, COM-подключение/file IPC, undo/redo, разбор координат, базовые примитивы (линии, полилинии, прямоугольники, дуги, окружности, эллипсы, штриховки, mtext, линейные/угловые/радиальные размеры, выноски).

## 4. Стандарт слоёв (предложение для обсуждения и правки)

Именование по аналогии с распространённой практикой AR-* (Architectural), адаптировано под номенклатуру Полиснаба:

| Слой | Назначение | Цвет (ACI) | Тип линии |
|---|---|---|---|
| `AR-WALL` | контур стен модуля | 7 (белый/чёрный) | Continuous |
| `AR-WALL-INSUL` | штриховка утеплителя (150мм Arctic / 75мм Standard) | 8 | Continuous |
| `AR-DOOR` | дверные проёмы | 1 (красный) | Continuous |
| `AR-WIND` | оконные проёмы | 5 (синий) | Continuous |
| `AR-VENT` | вентиляционные проёмы/короба | 3 (зелёный) | Continuous |
| `AR-VESTIBULE` | тамбур-шлюз (для Arctic-серии) | 6 | Continuous |
| `DIM` | размерные линии | 2 (жёлтый) | Continuous |
| `TEXT` | текст, надписи, спецификации | 7 | Continuous |
| `AXIS` | осевые линии | 4 | Center |
| `TITLE-BLOCK` | штамп, рамка листа | 7 | Continuous |
| `HATCH-FLOOR` | штриховка пола (150мм / 75мм) | 9 | Continuous |

*(Финальные ACI-коды и имена слоёв — под правку, это стартовый черновик для Claude Code, чтобы было от чего оттолкнуться)*

## 5. Размерный стиль (Dimension Style)

Требования под соответствие СПДС/ЕСКД:
- Единицы: миллиметры, точность — целые мм (без десятичных, если не указано иное).
- Стрелки: засечки (архитектурный тип) или замкнутые стрелки — выбрать один и закрепить как стандарт.
- Текст размера: над размерной линией, шрифт — единый текстовый стиль проекта (uniform с остальными надписями).
- Выносные линии: с зазором от контура ~1-2мм, вылет за размерную линию ~2-3мм.
- Один именованный dimstyle (`POLISNAB-DIM`), который создаётся один раз инструментом `setup_dimstyle` и переиспользуется.

---

## 6. Штамп (основная надпись, ГОСТ 2.104)

Блок с атрибутами, вставляемый в правый нижний угол листа:

- Обозначение документа (шифр)
- Наименование изделия (тип модуля)
- Масштаб
- Лист / Листов
- Разработал / Проверил / Н.контроль / Утвердил (ФИО, дата)
- Название организации — «ООО «ПОЛИСНАБ»
- Литера (для стадии проекта, если применимо)

Реализация: DXF/DWG block с editable attributes (`ATTDEF`), инструмент `insert_title_block(project_name, scale, sheet_num, ...)`.

---

## 7. Параметрическая библиотека узлов

Функции-генераторы (Python), принимающие параметры и выдающие геометрию через существующие низкоуровневые инструменты (line/rectangle/dimension):

- `draw_module_outline(length_mm, width_mm, wall_thickness_mm)` — базовый контур
- `insert_door(wall_side, offset_mm, width_mm)` — проём двери со стандартной шириной
- `insert_window(wall_side, offset_mm, width_mm, height_mm)` — оконный проём
- `insert_vent_duct(wall_side, offset_mm, diameter_mm)` — вентиляционный короб
- `insert_vestibule(depth_mm, width_mm)` — тамбур-шлюз (для Arctic-серии)

Это уже прямой мост к вашим функциональным блокам (столовая/кухня, санблок, сушилка, медблок, штаб/офис, КПП, склад) — каждый блок станет комбинацией этих примитивов с своим набором параметров.

---

## 8. Поэтапный план

**Phase 0 — done:** форк репозитория, тест headless/live на простом прямоугольнике (уже пройдено).

**Phase 1:** реализовать `setup_layers()` и `setup_dimstyle()` — один вызов, создающий весь стандарт слоёв и размерного стиля в новом чертеже. Тест: контур модуля условного размера (например 6000×2400мм) с корректными слоями и размерными линиями.

**Phase 2:** блок штампа + инструмент вставки, тест на том же чертеже — полноценный лист с рамкой и штампом.

**Phase 3:** параметрические узлы (двери/окна/вентиляция/тамбур) + первый готовый шаблон одного функционального блока (например, санблок — он самый геометрически простой).

**Phase 4 (позже, не сейчас):** связка с региональными таблицами параметров (R0–R4, E0/E1, W0–WX) — автоматический подбор толщин утепления и типа проёмов по нормативным данным.

## 9. Стартовая задача для Claude Code

Скопировать в терминал в папке форкнутого репозитория:

```
Изучи структуру проекта autocad-mcp. Найди, где определены инструменты (tools) для работы со слоями и размерными стилями. Создай новый модуль polisnab_standards.py с функциями setup_layers() и setup_dimstyle(), реализующими стандарт слоёв и размерного стиля из PROJECT-BRIEF-autocad-mcp-polisnab.md (раздел 4 и 5). Зарегистрируй их как MCP-инструменты по аналогии с существующими. После — протестируй на прямоугольном контуре 6000x2400мм.
```
